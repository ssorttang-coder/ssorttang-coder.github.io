세이프가드(SafeGuard) 개인정보처리방침

마지막 업데이트: 2026년 10월 15일
세이프가드는 사진 속 개인정보 검출과 보이스피싱 통화 분석을 모두 사용자 기기 안에서만 수행하며, 통화 음성·통화 내용(전사)·사진을 외부 서버로 전송하거나 수집하지 않습니다. 단, 사용자가 직접 켠 보호자 알림 기능은 위험 통화가 감지됐을 때 보호자에게 카카오 알림톡을 보내기 위해 위험도·시각 등 최소한의 정보를 전송합니다(2.3항). 무료 버전의 광고와 관련해 Google AdMob이 별도로 데이터를 수집할 수 있습니다(4항).

1. 개요

본 개인정보처리방침은 '세이프가드(SafeGuard)'(이하 '앱')의 서비스 이용과 관련하여 사용자의 개인정보 보호에 관한 정책을 안내합니다. 본 앱은 사용자의 개인정보를 최우선으로 보호하며, 관련 법규를 준수합니다. 앱의 모든 분석(사진 속 개인정보 검출, 통화 녹음 기반 보이스피싱 분석)은 100% 사용자 기기 내에서 이루어집니다.

2. 수집하는 개인정보

사진과 통화 녹음의 처리·분석은 모두 사용자 기기 안에서 진행되며, 사진·통화 음성·통화 내용(전사)·분석 상세는 서버로 전송하지 않습니다. 사용자가 켠 선택 기능인 보호자 알림(2.3항)을 사용할 때에만 아래에 적은 최소한의 정보가 전송됩니다. (무료 버전의 광고와 관련하여 Google AdMob이 별도로 데이터를 수집할 수 있습니다 — 4항 참조.)

2.1 이미지 데이터

  • 앱은 사용자가 선택·허용한 이미지에 접근하여 분석합니다.
  • 이미지 분석 과정에서 읽을 수 있는 개인정보(주민등록번호, 여권번호, 운전면허번호, 전화번호, 이메일, 신용카드번호 등)는 오직 기기 내에서만 처리됩니다.
  • 분석된 정보는 처리 후 메모리에서 즉시 삭제되며, 어떠한 형태로도 저장되거나 외부로 전송되지 않습니다.

2.2 통화 녹음 데이터 (통화 디펜더)

보이스피싱 통화 분석 기능(통화 디펜더)은 다음 원칙에 따라 동작합니다.

  • 앱은 통화를 직접 녹음하지 않습니다. 마이크 녹음 권한(RECORD_AUDIO)을 사용하지 않습니다.
  • 사용자가 휴대폰 전화 앱에서 직접 켠 '통화 자동 녹음' 등으로 이미 저장한 본인의 통화 녹음 파일만 읽기 전용으로 접근하여 분석합니다. 파일을 수정·삭제·업로드하지 않습니다.
  • 음성 인식(STT)과 분석은 100% 기기 내에서 수행되며, 통화 음성과 전체 전사 내용은 저장하지 않고 분석 후 메모리에서 처리됩니다.
  • '자동 보호'가 켜져 있으면 통화가 끝나는 시점만 감지(전화 상태 권한)해 새 녹음을 지체 없이 분석합니다. 이 과정에서도 통화 내용·통화 기록·전화번호는 수집·전송하지 않습니다.
  • 분석 결과는 마스킹된 경량 메타데이터(위험도·요약 등) 형태로만 기기 내에 보관되며, 위험도별 차등 보관기간이 지나면 자동 삭제됩니다. 사용자는 앱 내에서 언제든 분석 내역을 직접 전체 삭제할 수 있습니다.

2.3 보호자 알림 (선택 기능)

사용자가 보호자(가족)를 등록하고 보호자가 직접 동의한 경우에만, 위험 통화가 감지되면 보호자에게 카카오 알림톡을 보냅니다. 이를 위해 다음 정보가 전송됩니다.

  • 보호자 휴대전화번호: 알림톡을 받을 곳(수신처)으로만 사용됩니다. 서버에는 번호를 변환(해시)한 값으로만 동의·발송 한도 기록을 남깁니다.
  • 위험도와 시각: 위험 단계(예: 위험, 매우 위험)와 통화가 끝난 시각(시·분).
  • 금융 앱이 열린 시각(2.4항 기능을 켠 경우): 금융 앱이 처음 열린 시각(시·분)과 그것이 통화 중이었는지 통화 뒤였는지. 어떤 앱인지(앱 이름)는 전송하지 않습니다.
  • 기기 구분용 무작위 ID: 동의한 보호자에게만 보내고 같은 통화로 알림이 반복되지 않도록 쓰는 임의의 값입니다. 이름·전화번호 등 사용자를 직접 알아볼 수 있는 정보가 아닙니다.

통화 음성, 통화 내용(전사), 통화 상대의 전화번호·이름은 전송하지 않습니다. 보호자 알림은 앱에서 언제든 끌 수 있고, 보호자는 알림톡의 안내에 따라 언제든 수신을 거부할 수 있습니다.

2.4 금융 앱 열림 확인 (선택 기능)

사용자가 앱 안의 안내에 동의하고 휴대폰 설정에서 '사용 정보 접근'을 허용한 경우에만 동작합니다.

  • 위험 통화가 감지되면, 통화 중이나 그 뒤(경보 후 최대 30분)에 은행·증권·카드·간편결제·가상자산 거래소 앱이 화면에 열렸는지와 그 시각만 기기 안에서 확인합니다. 확인 대상 앱 목록은 회사 서버에서 내려받아 갱신하며, 이때 개인정보는 보내지 않습니다.
  • 확인 대상 앱 목록에 없는 앱의 기록은 바로 버리며, 설치된 앱 목록이나 앱 사용 기록을 저장하거나 전송하지 않습니다.
  • 앱 화면의 내용, 금액, 계좌, 송금 여부는 알 수 없고 확인하지도 않습니다.
  • 확인 결과는 본인 기기의 경고 알림과, 보호자 알림을 켠 경우 2.3항의 범위(앱 이름 없이 시각만)로만 쓰입니다.
  • 앱의 보호자 관리 화면에서 끌 수 있으며, 휴대폰 설정에서 '사용 정보 접근'을 해제할 수도 있습니다. 회사 프로필·보안 폴더에 설치한 앱은 확인되지 않습니다.

3. 필요 권한 및 사용 목적

앱이 요청하는 권한과 그 목적은 다음과 같습니다.

  • 사진/미디어 접근(이미지): 사용자 갤러리의 이미지를 분석하기 위해 필요합니다.
  • 오디오 파일 접근: 기기에 저장된 통화 녹음 파일을 읽어 보이스피싱을 분석하기 위해 사용됩니다(직접 녹음이 아닌 읽기 전용).
  • 알림: 위험 통화 및 분석 결과를 안내하기 위해 사용됩니다.
  • 배터리 최적화 제외(선택): '자동 보호' 사용 시 통화 종료 직후 지연 없는 분석을 위해 사용자 동의 하에 1회 요청합니다.
  • 전화 상태 확인(선택): '자동 보호' 사용 시 통화가 끝나는 시점을 감지해 새 통화 녹음을 즉시 분석하기 위해 사용됩니다. 통화의 시작·종료 여부만 확인하며, 통화 내용을 녹음하거나 통화 기록(통화 목록)을 읽지 않고, 전화번호·통화 상대 정보를 수집·전송하지 않습니다. '자동 보호'를 켤 때 안내 팝업과 함께 사용자 동의 하에 1회 요청하며, 허용하지 않아도 자동 보호는 동작합니다.
  • 생체 인증(선택): 보관함 잠금 해제에 사용됩니다.
  • 사용 정보 접근(선택): '금융 앱 열림 확인'(2.4항)을 켠 경우, 위험 통화 뒤 금융 앱이 화면에 열린 시각을 기기 안에서 확인하기 위해 사용됩니다. 앱 안의 안내와 동의를 거친 뒤 사용자가 휴대폰 설정에서 직접 허용합니다.

앱은 다음 권한을 사용하지 않습니다: 마이크 녹음(RECORD_AUDIO), 통화 기록(READ_CALL_LOG), 발신 전화(CALL_PHONE), 문자 송수신(SMS), 접근성 서비스.

4. 제3자 서비스 사용

앱은 다음과 같은 제3자 구성요소를 사용합니다.

  • Google ML Kit: 이미지 내 텍스트 인식 및 라벨링에 사용됩니다(기기 내 동작).
  • TensorFlow Lite: 문서 유형 감지를 위한 머신러닝 모델 실행에 사용됩니다(기기 내 동작).
  • whisper.cpp(온디바이스 음성 인식): 통화 녹음의 한국어 음성을 텍스트로 변환하는 데 사용됩니다(기기 내 동작, 외부 전송 없음).
  • Google AdMob(광고): 무료 버전에 광고를 표시합니다. AdMob은 광고 제공·측정을 위해 광고 식별자 등 일부 데이터를 수집할 수 있으며, 이는 Google의 정책(policies.google.com/privacy)을 따릅니다. 프리미엄(세이프가드 Plus) 구독 시 광고가 제거됩니다.
  • Google Play 결제: 프리미엄 구독 결제는 Google Play를 통해 처리되며, 앱은 결제 정보를 수집·보관하지 않습니다.
  • Google Firebase(Cloud Functions·Firestore): 보호자 알림(2.3항)의 동의 확인과 발송 요청 처리에 사용됩니다. 알림 요청은 서울 리전의 서버에서 처리됩니다.
  • SOLAPI·카카오 알림톡: 보호자에게 카카오 알림톡을 보내는 데 사용됩니다(보호자 휴대전화번호와 알림 문구에 들어가는 위험도·시각 정보).

ML Kit·TensorFlow Lite·whisper.cpp는 오직 기기 내에서만 작동하며, 사용자의 데이터를 외부로 전송하지 않습니다.

5. 개인정보 보호 조치

  • 모든 이미지·통화 분석은 100% 기기 내에서 이루어집니다.
  • 분석 과정에서 생성된 임시 데이터는 처리 완료 후 자동으로 삭제됩니다.
  • 통화 음성·통화 내용(전사)·사진은 서버에 저장하거나 전송하지 않습니다. 보호자 알림을 켠 경우에도 2.3항의 최소 정보만 암호화된 연결(HTTPS)로 전송합니다.

6. 사용자의 권리

  • 사용자는 언제든지 기기의 설정에서 앱에 부여한 권한을 취소할 수 있습니다(취소 시 관련 기능이 제한될 수 있습니다).
  • 통화 '자동 보호'는 앱 내 토글로 끌 수 있으며, 분석 내역은 앱 내에서 직접 전체 삭제할 수 있습니다.
  • 보호자 알림과 금융 앱 열림 확인은 앱의 보호자 관리 화면에서 각각 끌 수 있으며, 보호자는 알림톡의 안내에 따라 수신을 거부할 수 있습니다.
  • 프리미엄 구독을 통해 광고를 제거할 수 있습니다.

7. 데이터 삭제 요청

온세이프가드(세이프가드, 개발자: JSTColab)는 다음 방법으로 데이터 삭제를 요청받습니다.

  1. 앱에서 직접: 보호자 관리 화면에서 보호자를 삭제하거나 보호자 알림·금융 앱 열림 확인을 끄면 그 뒤로는 정보가 전송되지 않습니다. 분석 내역은 앱에서 전체 삭제할 수 있고, 앱을 삭제하면 기기 안의 데이터가 모두 지워집니다.
  2. 보호자: 알림톡과 동의 페이지의 안내에 따라 언제든 수신 거부·동의 철회를 할 수 있습니다.
  3. 이메일: jstcolabs@gmail.com 으로 제목 '데이터 삭제 요청'과 함께 보호자 휴대전화번호를 보내 주시면, 확인 뒤 30일 안에 서버에 남은 해당 보호자의 동의 기록과 발송 기록을 삭제하고 결과를 회신해 드립니다.

서버에 남는 데이터와 보관 기간

  • 보호자 동의 기록(전화번호를 변환한 값): 동의 철회 또는 삭제 요청 때까지 보관합니다.
  • 발송 한도·중복 방지 기록(전화번호를 변환한 값, 날짜별 횟수): 발송 남용을 막기 위해 보관하며, 삭제 요청 시 함께 삭제합니다.
  • 보호자 추가 알림의 중복 방지 기록(무작위 ID를 변환한 값과 시각): 48시간 뒤 자동 삭제됩니다.
  • 통화 음성·통화 내용(전사)·사진은 서버에 저장하지 않으므로 서버에서 삭제할 대상이 없습니다.
  • 광고(Google AdMob)와 앱 분석·오류 보고(Google Firebase) 데이터는 Google의 정책과 보관 기간에 따라 처리됩니다.
