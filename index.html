통화가 끝나면,
보이스피싱 신호를 자동으로 살핍니다

자동 보호를 켜두면 모르는 번호와의 통화가 끝났을 때, 휴대폰에 저장된 통화 녹음을 백그라운드에서 분석해 위험도를 알려드립니다.

  • 통화 종료 후 자동 분석

    수사기관·금융기관 사칭, 안전계좌·대포통장, 원격제어 앱 설치, 송금 유도처럼 보이스피싱에서 자주 나타나는 신호를 찾아냅니다.

  • 위험도 점수 + 알림

    통화별 위험도를 점수로 보여주고, 위험·심각으로 판단되면 알림으로 알려드립니다.

  • 분석 내역 · 자동 삭제

    분석된 통화를 모아 보고, 안전·주의·위험에 따라 일정 기간이 지나면 자동 삭제합니다. 번호와 통화 내용은 가려서 보관합니다.

예시 — 통화 위험도 85 / 100
금융기관 사칭 안전계좌 안내 송금 유도

이 앱은 통화를 직접 녹음하지 않습니다. 전화 앱에 저장된 녹음 파일을 읽기만 합니다. 분석 결과는 참고용이며, 음성 인식 기반 추정이라 정확하지 않을 수 있어요. 의심되면 경찰 112 · 금융감독원 1332로 직접 확인하세요.

  • 전화 앱의 '통화 자동 녹음' 설정이 켜져 있어야 분석할 녹음이 생깁니다.
  • 저장된 연락처(가족 등)와의 통화는 분석하지 않습니다 — 모르는 번호 위주로 살펴봅니다.

자주 묻는 질문

궁금한 점을 모았어요

01 통화를 직접 녹음하나요?
아니요. 세이프가드는 통화를 직접 녹음하지 않습니다. 마이크 녹음 권한을 사용하지 않으며, 휴대폰 전화 앱의 '통화 자동 녹음'으로 이미 저장된 본인의 녹음 파일만 읽어서 분석합니다. 파일을 수정·삭제·업로드하지 않습니다.
02 특정 통신사만 되나요?
통신사와 무관하게 사용할 수 있습니다. 특정 통신사 가입자 전용이 아닙니다. 다만 전화 앱에서 '통화 자동 녹음'을 켜두셔야 분석할 녹음 파일이 생깁니다.
03 가족(저장된 연락처) 통화도 분석되나요?
아니요. 휴대폰에 저장된 연락처(가족·지인 등)와의 통화는 분석하지 않습니다. 보이스피싱 위험이 큰 모르는 번호 위주로 살펴봅니다. 또한 전화 앱의 '통화 자동 녹음' 설정이 켜져 있어야 분석할 녹음이 생깁니다.
04 분석 결과가 정확한가요?
분석 결과는 음성 인식 기반 추정이며 참고용입니다. 정확하지 않을 수 있고, 통화가 끝난 뒤 분석해 알려드리는 방식이라 통화 중 실시간 차단이 아닙니다. 의심되면 경찰 112·금융감독원 1332로 직접 확인하시길 권장합니다.
의심 통화는 112 · 1332로 확인하세요
05 무료와 유료는 어떻게 다른가요?
사진 개인정보 검출(전체 스캔·카메라 자동 검사·클립보드 보호)은 무료로 이용할 수 있습니다. 통화 디펜더(보이스피싱 통화 분석)는 음성 인식 모델을 받고 자동 보호를 켜는 기능이라 프리미엄(Plus) 구독으로 제공됩니다. 월 4,900원 / 연 39,000원입니다.
